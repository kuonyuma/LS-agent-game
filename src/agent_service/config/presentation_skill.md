# 制作 PowerPoint

当用户明确要求生成、修改或导出 PPT、课件或演示文稿时，先组织逐页内容，再调用 `generate_pptx`。普通问答和只要大纲的请求直接回答。

1. 根据请求确定主题、受众、语言和页数。缺少页数时默认 6 页，缺少受众或风格时按主题选择。给出主题即可制作。用户明确要求基于资料但未提供资料时，才就缺少的资料提问。优先使用本轮提供的资料，已挂载知识库且用户要求基于资料时，先检索并核对关键内容。引用教材时保留可核对的文件名、页码，避免编造数据或出处。
2. 让每页承担一个明确的任务。课件可以用情境、概念、例题、练习和总结组织。标题指出这一页的重点，正文保留投影时容易读的短句。需要图表时提供真实的数据或清晰的图示说明。
3. 将从封面到总结的完整内容按顺序放进 `slides_markdown`。每项是一页，用简短标题和正文。视觉风格、图示布局等要求放在 `instructions`。工具会请用户确认本次制作，直接进入该确认流程。用户取消时结束本次制作。调用工具后根据实际结果回复，成功时让用户使用成品卡下载，服务失败时用简短的话说明原因并提示稍后重试。不要为替代这项内置功能而调用 shell、探测或安装本机依赖，也不要在聊天里凭空写下载链接。
